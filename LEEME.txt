Contenido: Todo lo necesario para install-prod.sh en 1 comando - 12 pasos

INSTRUCCIONES RÁPIDAS:
1. Sube abogadogratis-prod-package.zip a tu VPS /tmp/
2. Descomprime en /opt para generar /opt/abogadogratis/:
   sudo apt install -y unzip
   sudo mkdir -p /opt
   sudo unzip -o /tmp/abogadogratis-prod-package.zip -d /opt/
   # Esto crea /opt/abogadogratis/ (si crea /opt/abogadogratis-prod-package, renombra: sudo mv /opt/abogadogratis-prod-package /opt/abogadogratis)
   sudo chown -R root:root /opt/abogadogratis
   sudo chmod +x /opt/abogadogratis/install-prod.sh /opt/abogadogratis/deploy.sh /opt/abogadogratis/qdrant/backup-cron.sh
3. Crea Website y Database en ISPConfig (ver INSTRUCCIONES.md)
4. Ejecuta:
   cd /opt/abogadogratis
   sudo ./install-prod.sh
